# Pinkerton
## Simple zero-dependency Go health-check app
The idea behind Pinkerton is to provide a way to quickly track outages and connection issues in development environment.
Whenever you need to check if your services are alive you just add the service to your `docker-compose.yml` and use cli to add and query services statuses.
